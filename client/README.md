# client

React Router (framework mode) + TypeScript + Tailwind + shadcn/ui, built with Vite.

## Development

```sh
npm install
npm run dev
```

Runs at http://localhost:5173. See the root `README.md` to run this alongside the API and DB.

## Build

```sh
npm run build
```

Outputs `build/client` (static assets) and `build/server` (SSR server) — see [React Router docs](https://reactrouter.com/) for deployment options.
